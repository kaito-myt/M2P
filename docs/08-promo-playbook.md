# 08 — 販促プレイブック（本紹介 SNS の勝ちパターン）

Kindle 実用書/ビジネス書/自己啓発の SNS 販促（Instagram / X / TikTok）で「売れる/伸びる」投稿の
実装可能ルール集。web リサーチ（2026-07）に基づく。**販促画像コンポーザ・戦略プレイブックエージェント・
TikTok 台本ジェネレータの設計根拠**として使う。関連: [[project_promotion_features]]、docs/05 販促付録。

## 1. IG フィード販促「画像」設計（購買を動かす）

勝ち型は **ベネフィット見出しが主役・表紙は"証拠"**（表紙単体では売れない）。コンポーザ実装ルール:

1. **アスペクト比 4:5（1080×1350）**。上下 ~120px はセーフゾーン（UI 被り）＝テキスト置かない。
2. **見出し＝最大要素**。ベネフィット/好奇心ギャップ1行、1行13–20字・最大2行、上1/3を占有、bold/black 90–140px。
3. **数字・具体で**。「3つの習慣」「月5万円」「1日10分」。数字はアラビア数字。
4. **アクセント色は1つだけ**。ベース=白/近黒、ペイオフ語だけ蛍光バンド/色文字で強調。強調は2要素まで。
5. **高コントラスト・フォント2種以内**。画像上テキストは半透明スクリムで可読性 4.5:1 以上。
6. **KU バッジ**。対象なら右上にリボン/ピル「Kindle Unlimited 読み放題」「★KU 0円」。ゼロリスク訴求＝強い転換レバー。
7. **表紙サムネは隅**（フレームの30%以下・影付き）で"本物の本"に見せる。
8. **固定テンプレ＝ブランド想起**。色/フォント/ロゴ位置を全投稿で固定。
9. **How-to/リストはカルーセル＞単一**。1枚目=見出しフック、2–N=1要点ずつ、最終=表紙+CTA。5–8枚。保存/シェアを稼ぐ（2026最重要シグナル）。
10. **ジャンル別パレット**: money=緑/金、health=青/白、self-help=暖色オレンジ、競馬=芝グリーン+赤。per-genre トークン化。

## 2. キャプション（IG / X）

構造 = **Hook → Value → CTA（HVC）**:
- **1行目=結論/約束**（「〜な人が9割。実はこれだけで変わります」）。"…続きを読む"前の1行で決まる。
- **本文**: 価値3点＋補足1。短行・ブロック間に空行。絵文字は行頭マーカー（✅▶️📌）を1行1個まで。
- **長さ**: IG 150–500字（価値を前に）。X ≤140字/tweet、how-to は5–7連スレッド。
- **検索KWを自然文に織り込む**（IG はキャプション本文もインデックス）。
- **CTA**: IG キャプション内リンクは不活性 → bio 誘導「詳細はプロフィールのリンクから📚」。**bio リンク先の先頭=Amazon/KU ページ（or /books ランディング）**。「保存して後で」「コメントで教えて」でシグナル増。X は最後のtweetに Amazon リンク。
- **価値:宣伝 = 8:2**。

## 3. ハッシュタグ

- **数=10–15**（旧30より質）。3層ミックス:
  - **ビッグ(>50万)**: #読書(~162万) #読書記録(~63万) #読了(~24万)
  - **ミッド(5万–30万)**: #読書好きな人と繋がりたい(~25.5万) #本好きな人と繋がりたい(~18.4万) #読書倶楽部 #活字中毒
  - **ニッチ(<5万・ジャンル/意図)**: #ビジネス書 #自己啓発本 #お金の勉強 #副業 #Kindle出版 #kindleunlimited #競馬予想 ← ここが転換する
- **比率 ~ ビッグ2 / ミッド5 / ニッチ5–8**。ニッチのtopに載る狙い。
- **配置**: 先頭コメントに置きキャプションを綺麗に（リーチ同等）。タグセットは回転させる。

## 4. 投稿頻度・時間（JP）

- **IG フィード/カルーセル: 20:00–22:00**、水木寄り。Reels は peak の1–2h前(18–19時)。初速が命。
- **X: 7–8時/12時/21–23時**（夜が最活発）。
- **TikTok: 19:00–23:00**、次点12:00/7:00。
- **頻度**: IG 3–5回/週+毎日stories、X 2–3投稿/日、TikTok 最低1回/日（量が発見を生む）。
- 複利は **~3ヶ月**。初期は実験と割り切る。

## 5. TikTok テンポ（台本ジェネレータ）

- **尺: 21–34s**（1冊フック）。上限45s。
- **フックは ≤1s**（音声＋画面テキスト両方）。最初3sの維持率<70%で失速。フック型:
  - 警告: 「〇〇してる人、今すぐやめて」/ リスト: 「お金が貯まる人の3つの口癖」
  - 好奇心ギャップ: 「この本の"ある1ページ"で人生変わった」/ 逆張り: 「9割が知らない〇〇」
- **構成**: フック(0–1s)→緊張/理由(1–4s)→ペイオフ3ビート→クリフハンガー/CTA。最良点は最後まで引っ張る（リプレイ/コメント誘発）。
- **カット尺: 各1.5–3s、8–12シーン**。静止1フレームを3s超保持しない。
- **画面テキスト**: 各シーンに8–16字、ナレーションに同期、中央セーフゾーン（下15%はUI/字幕で避ける）。
- **ナレーション**: 早口 ~6–7モーラ/秒、無音を作らない。~120–160字/30s。
- **音楽**: 今トレンドの音源（毎週確認）、VO下で小さく。
- **キャプション**: フック1行＋タグ3–5（#本紹介 #読書 #ビジネス書 #kindle）。CTA「続きはプロフから📚」。
- **ジェネレータ既定**: `scenes=8–12`, `sec_per_scene=1.5–3`, `total=21–34s`, `hook_type∈{warning,list,curiosity,contrarian}`, `payoff_beats=3`, `cliffhanger=true`。

## 6. A/B テスト変数と勝ち指標

| 変数 | テストする値 |
|---|---|
| 見出し型 | 数字リスト / 好奇心ギャップ / 警告 / ビフォーアフター |
| 画像レイアウト | テキスト主役 / 表紙主役、単一 / カルーセル |
| アクセント色 | ジャンル別パレット |
| KU バッジ | 有 / 無 |
| フック型(TikTok) | 上記4型 |
| 動画尺 | 15 / 25 / 35s |
| CTA文言 | プロフのリンクから / 保存して後で / コメントで |
| ハッシュタグ | ビッグ寄り / ニッチ寄り |
| 投稿時間 | 20:00 / 21:00 / 12:00 |
| キャプション長 | 短打 / フルHVC |

**勝ちフォーマット指標（優先順）**:
1. **シェア/送信(IG)・完了+再視聴%(TikTok)** ＝ 2026 の発見シグナル最上位
2. **保存**（how-to の購買意図プロキシ）
3. **bio リンクCTR/プロフ訪問**（Amazon クリックに最も近い）
4. リーチ/インプレ → いいね（最弱）

**1変数ずつ**・1アーム 5–7投稿。いいねでなく **シェア+保存+リンクCTR** を上げたアームを採用。

## 9. 2026-09-02 全面リブート（SNS成長診断に基づく実装）

10ヶ月運用の実測（X: 279投稿で平均表示3.5・フォロワー21、IG: 時間25件上限到達、TikTok: spam_risk停止）を受け、
競合検証20件（精神科医Tomy 39.2万・ゆーき11.3万・けんご52.9万・note実録型ほか）とのギャップ分析から方針を全面転換した。
詳細な診断はレポート「栞 SNS成長診断」（artifact）。**本章が現行の運用ルール（§1〜8と矛盾する場合は本章優先）**。

### 診断の要点（なぜ伸びなかったか）
1. **スパム挙動**: 7.4投稿/日＋全投稿同一タグ（#読書記録×198）＋会話ゼロ → アルゴリズムが配信を抑制。
2. **ブランド分裂**: 5媒体5名（よみとも/しおり/夜ふけの一冊/良い本を読む習慣/積ん読ラボ）＋架空の経歴。
3. **三次情報のみ**: 伸びる競合は全員が一次情報持ち。「AIで本を作り売っている」当事者実績が未使用。
4. **計測なし**: メトリクス取得はXのみ、日次レビュー無効。

### 実装済みの転換（2026-09-02）
- **頻度**: value枠 3→2/日（`promotion-content-generate.ts` VALUE_SLOTS 09:00/20:00）、promo は promoter プロンプトで
  **1冊あたり x_posts 最大3本**。合計 7.4/日 → 2〜3/日。バースト投稿禁止。
- **ハッシュタグ**: core は ブランドタグ **#栞の本棚** のみ。話題タグは rotating（本文一致で自動付与）。同一タグの機械的反復を廃止。
- **アイデンティティ**: x/instagram/note の display_name/bio/concept を「**栞（AI×出版レーベル）**」に統一。
  経歴は実データの肩書（刊行数等）のみ。※プラットフォーム上の表示名変更は運営者の手動作業。
- **コンテンツの柱（content_pillars = few-shot 実体）**:
  - X: ①断言型140字完結（お金）②同（習慣・仕事術）③**制作実録**（刊行数・売れ行き・失敗の実数）④問いかけ（リプ喚起）。リンクなし。
  - IG: カルーセル「1投稿=1悩み解決」6枚構成（悩みの言語化→共感→学び3つ→引用→誰に効くか→保存CTA）週3〜5＋月1実録。
  - note: **制作実録 週1**＋悩み解決ロング＋**月次実数公開**（無料7割・有料は完全版のみ）。
  - **競馬・ラノベ・古典の柱は凍結**（お金・習慣・仕事術に集中）。
- **運用**: 投稿後30分はリプ返し。promo は1日1本/チャンネルまで（バックログはこのポリシーで間引く）。

### 未実装（次の増分）
- P3計測: IG/TikTok/note のメトリクス取得・全チャンネルのフォロワースナップショット・promo_daily_review 有効化。
- TikTok 復旧: spam_risk 解除＋投稿経路（API承認）— 復旧後は「30秒・内容フック型」（けんご型の実用書版）で参入。

## 10. ペルソナ人物描写ルール + IG カルーセル実装（2026-09-18、運営者要望）

男性フォロワー増加を狙い、ペルソナの人物画像/動画描写ルールを統一し、IG をカルーセル投稿に切替えた。
実装は `docs/05-program-design.md` 該当節を参照。ここでは**内容ルール**を記録する。

### 人物描写ルール（`PERSONA_VISUAL_RULES`）
- **顔は絶対に映さない**。フレーミングは首から下のみ（鎖骨〜太もも上）。顔・頭部は画面外/カットオフ。
  後ろ姿・手元・胸元〜腰まわりのクローズアップは可。
- **20代女性、スタイルの良い体型を強調する、フェミニンでかなりセクシーな服装**
  （体のラインが出るニット/ブラウス、タイトスカート/ショートパンツ、オフショルダー等）。
- **禁止**: 下着姿・ヌード・過度な露出・性的な行為やポーズ。清潔感と上品さを保ち、
  Instagram/TikTok/X の利用規約に準拠する健全な範囲に収める。
- 「もし人物を描く場合は」という条件付きルールとして、avatar/banner・IGカルーセル固定テンプレ枚・
  TikTok/IGリールの Veo 実写級フックなど人物が映り得る全生成箇所に共通付加する。

### §1 の更新: IG カルーセル最終枚 = 固定テンプレ枚（コード実装済み）
§1-8「固定テンプレ＝ブランド想起」を具体化: IG カルーセルの**最終枚**は上記ルールに沿ったペルソナ写真
（本を持つ/読書中の首から下カット）＋固定 CTA コピー「フォローで毎日、本の学びをひとつ」を敷いた
**1枚をチャンネルごとに1回だけ生成し使い回す**（毎回生成しない）。構成は 1枚目=見出しフック(既存の
販促画像/バリューカード) → 2〜N枚目=本文から抽出した要点カード(1文=1枚) → 最終枚=固定テンプレ、
合計3〜6枚。差し替えたい場合は `scripts/regen-channel-visuals.mjs --force` で作り直す。

## 11. キャラクター性ルール（2026-09-18、運営者要望「投稿もSNSのキャラクター性が出るように」）

投稿本文（テキスト）に、フォロワーが「同じ人（ことは）が書いている」と感じる一貫した人柄を出す。
実装は `docs/05-program-design.md` F-097 節を参照。ここでは**内容ルール**を記録する。

### ペルソナ「ことは」
5チャンネル（X/Instagram/TikTok/note/blog）共通の書き手人格。20代後半・都内会社員・読書女子。
Kindle Unlimited で毎日1冊読む生活を3年続けている。一人称「わたし」、口癖5個（「〜なんだよね」
「正直に言うと」「これは刺さった」「地味だけど効く」「気づいたら〇時間経ってた」）、好き/苦手なもの、
価値観（背伸びしない・続けられる小さな学び）、弱み（三日坊主・朝弱い）を持つ。定義は
`packages/contracts/src/agents/sns-strategist.ts` の `DEFAULT_PERSONA_CHARACTER_SHEET`（600〜900字）。
`promotion_channel_settings.strategy_json.character_sheet` で運営者がチャンネル別に上書き可能
（未設定なら既定ペルソナへ自動フォールバック、`resolveCharacterSheet()`）。

### 投稿への反映ルール
- **毎投稿に人柄の要素を最低1つ**入れる: 口癖・日常の一コマ・率直な感情・自分の失敗談のいずれか。
- **主役は本の紹介・価値提供**。自分語りは投稿全体の**2〜3割まで**（販促投稿の x_posts のように
  短い場合は一言添える程度でよい）。
- 自分語りを入れても「事実の扱い」（価格/URL/セール/未確定実績を書かない, §販促プレイブック本文の
  該当ルール）は破らない。
- キャラクター設定にある NG（説教くさい言い方・専門用語の羅列・顔出し）は守る。
- 対象エージェント: `content_creator`（育成投稿）・`promoter`（x_posts/note_article/blog_outline）・
  `anp.promo`（note記事告知）。品質ゲート `content_optimizer` が、本文に人柄の要素が無ければ
  自然に1つ補う（無理に増やしすぎない）。
