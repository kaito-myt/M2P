A2P 本番は Railway プロジェクト **balanced-joy**（env: production, region: sfo）で稼働。2026-06-17 に web + worker + postgres の3要素が全て Online。

- **A2P**（web/Next.js, GitHub kaito-myt/A2P 連携, Nixpacks）= https://a2p-production.up.railway.app
- **A2P-Worker**（graphile-worker, **空サービス**として作成し `railway up` でローカルからデプロイ。Dockerfile=`apps/worker/Dockerfile`, `RAILWAY_DOCKERFILE_PATH` 変数で指定）
- **Postgres**（postgres-volume）。外部接続は DATABASE_PUBLIC_URL（maglev.proxy.rlwy.net）。

要点（ハマりどころ）:
- **ログイン資格は env でなく DB の `users` テーブル**（`username`/`password_hash`）。env の AUTH_USERNAME/AUTH_PASSWORD_HASH はシード時のみ使用。本番は `miyata1229` / `Miyata11`（DB行を直接 update 済み）。`Miyata11` は公開リポジトリのE2Eに平文で存在するため本来は非推奨（ユーザー承知の上で採用）。[[feedback_autonomous]]
- **web は parseEnv を強制しないが worker は29項目を厳格検証**。NEXTAUTH_SECRET は64桁hex必須（プレースホルダだと worker のみ起動失敗）。NODE_ENV は web に付けると Next15.5 ビルドバグ、worker には production 必須。
- worker の環境変数は **Railway サービス間参照** `${{A2P.KEY}}` で web から配線（秘密をログに出さない）。DATABASE_URL は `${{Postgres.DATABASE_URL}}`。
- worker Dockerfile の実バグ4件を修正しコミット 837b21c（.dockerignore 追加 / deps ステージに packages/agents・packages/output/* の package.json 追加 / worker package.json に @anthropic-ai/sdk・openai 追加）。
- API キー（ANTHROPIC/OPENAI/GOOGLE）は web+worker 両方に設定済み。catalog.fetch の openai 価格は openai.com が HTTP 403 で取得不可（外部制限・graceful degradation で前回値保持）。
